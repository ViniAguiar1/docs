## 1. Conecte a sua receita

Em **Integrações**, escolha por onde você cobra. As origens convivem, e quem
cobra por mais de uma vê um MRR só.

**Stripe** conecta por OAuth. Nenhum token seu é armazenado: as chamadas usam a
chave de plataforma com um cabeçalho identificando a sua conta.

**AbacatePay** conecta colando uma chave de API. Gere uma **somente leitura** —
a mesma chave que lê é a que cobra, e o Keep não precisa desse acesso.

**Asaas** conecta colando uma chave de API **somente leitura**, como o
AbacatePay. O Keep detecta sozinho se a chave é de produção ou de sandbox.

Em todos os casos o acesso é de leitura: o Keep nunca cria, altera nem cancela
cobrança.

## 2. Gere uma chave de API

Em **Chaves de API**, clique em **Nova chave** e dê um nome que você reconheça
daqui a seis meses. É por ele que você vai decidir qual revogar.

<Warning>
  O segredo aparece uma única vez. Guardamos apenas o hash, então nem nós
  conseguimos mostrá-lo depois. Se perder, gere outro e revogue o anterior.
</Warning>

## 3. Mande atividade

Uma chamada do seu backend, onde você já sabe quem é o usuário. Uma por login
costuma bastar.

<CodeGroup>

```bash cURL
curl -X POST https://usekeep.dev/api/v1/activity \
  -H "Authorization: Bearer kp_live_..." \
  -H "Content-Type: application/json" \
  -d '{"customerId":"cus_ABC","email":"cliente@empresa.com"}'
```

```ts Node
await fetch("https://usekeep.dev/api/v1/activity", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEP_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    customerId: account.billingCustomerId,
    email: user.email,
  }),
});
```

```python Python
import os, requests

requests.post(
    "https://usekeep.dev/api/v1/activity",
    headers={"Authorization": f"Bearer {os.environ['KEEP_API_KEY']}"},
    json={"customerId": account.billing_customer_id, "email": user.email},
)
```

</CodeGroup>

<Tip>
  Mandar o `customerId` é o que faz o casamento ser exato: o mesmo id chega do
  outro lado, vindo da sua própria cobrança. Só com e-mail, vale a heurística de
  domínio — que falha justamente quando quem paga não é quem usa.
</Tip>

## 4. Espere duas semanas

O Keep compara os últimos 7 dias contra os 7 anteriores. Antes de existirem duas
janelas, não há o que comparar.

Se você quiser resultado imediato, mande um backfill: o endpoint aceita um array
de até 500 eventos por chamada, com `at` no passado.
